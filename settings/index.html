Phone scanning

Write this URL to an NFC tag (e.g. with the NFC Tools Android app) or call it from an iOS Shortcut. Anyone with this URL can fire your flow — treat it like a password.

Pass ?title=... and/or ?value=... on the URL to identify the tag. A first scan with new metadata creates a new entry below; later scans increment its counter and fire the flow.

Phone scanning

Phone-based scanning is not configured for this build. The app developer must register a webhook at tools.developer.homey.app/webhooks and set WEBHOOK_ID / WEBHOOK_SECRET in env.json before publishing.
